# OpenAPI 3.1 structural schemas

These resources are pinned local copies from the OpenAPI Initiative schema
catalog. Runtime validation is fully offline and never depends on the
availability or contents of a remote URL.

The root resource is `schema-base.json`. Unlike `schema.json`, it validates
OpenAPI Schema Objects with the official OpenAPI 3.1 JSON Schema dialect.
For the first release, custom values of `jsonSchemaDialect` are therefore not
supported.

Sources:

- https://spec.openapis.org/oas/3.1/schema-base/2025-11-23
- https://spec.openapis.org/oas/3.1/schema/2025-11-23
- https://spec.openapis.org/oas/3.1/dialect/2024-11-10
- https://spec.openapis.org/oas/3.1/meta/2024-11-10
